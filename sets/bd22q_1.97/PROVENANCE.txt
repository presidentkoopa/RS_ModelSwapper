RS Quest VR Weapons -- bd22q 1.97-pre (THE FLAGSHIP; generated, not imported)
=============================================================================

This is the one set in the depot that this repo's own tools produce. The other four are imported
or unpacked trees you can read and edit; this one is REGENERATED, and a hand edit to src/ is
drift -- tools/check_plan.py refuses a commit that changes it without the .generated stamp.

HOW TO REBUILD IT
  python tools/bd22_plus.py geometry
  python tools/bd22_plus.py apply
  python tools/bd22_mg.py
  python tools/bd22_plus.py revolver
  python tools/bd22_plus.py options
  python tools/bd22_plus.py bash
  python tools/bd22_plus.py whip
  python tools/bd22_plus.py butt
  python tools/bd22_plus.py pk3 dist/BD22Q_197pre.pk3

  Order matters: revolver after bd22_mg.py (it edits the roster handler bd22_mg.py writes), and
  options / bash / whip / butt after both. The result must equal this src/ -- diff it; that is the
  drift check on the generators themselves. `python`, not `python3`, on the owner's PC.

  .generated beside this file is the stamp the pre-commit hook looks for, written by the tools.

WHAT IS IN IT BEYOND 1.96b
  MG42 belt drum, Flamethrower canister and Unmaker skull reloads; the BD21 Machinegun; the BD21
  slug revolver; Speedloader / Per Round for both revolvers; the gun bash, the pistol whip and the
  two-handed butt strike. See HANDOFF.md for how each was measured and what is still untested.

NOT YET TESTED IN A HEADSET
