WHY
  Before this, this set existed in the depot only as that pk3 plus its build reports:
  the files were there but zipped, so the set could not be read or diffed the way
  sets/bd22q_1.97/src can. The pk3 in dist/ is unchanged and is still the built
  artefact; this is a readable copy of the same bytes.

WHAT THIS IS NOT
  It is not the set's SOURCE in the sense bd22q_1.97/src is. That set is regenerated
  by the tools in this repo. This one was generated from cards (genpack -> assemble ->
  mkpk3), and those cards live in RS_VR_Weapons, outside this depot. So this tree can
  be read and edited, but it cannot be regenerated from anything in here.
