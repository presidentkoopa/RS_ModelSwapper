// RS VR scopes, REAL mode (zscript/rsq/scope_real.zs).
//
// The surface the view down the bore is rendered into. One texture serves every scoped gun,
// because only one scope can ever be at the player's eye: scope_real.zs re-binds it to
// whichever gun's lens the player is actually looking through and swaps it onto that gun's
// glass surface, and the engine only re-renders a camera texture in a frame where something
// drew it (hw_entrypoint.cpp). While no scope is at the eye this costs nothing at all.
//
// The name is eight characters on purpose: ParseCameraTexture looks it up with
// TEXMAN_ShortNameOnly, so a longer one would be registered and then never found again.
// It must match RSQ_ScopeReal.TEXNAME / TEXNAME_N.
//
// 256x256 square. Square because the view through a scope is a circle; 256 because this
// ships on a standalone Quest and the lens is a couple of hundred pixels across at most --
// the cost that matters is the extra scene render, not the resolution, but there is no point
// paying for pixels nobody can resolve.
cameratexture RSQSCOPE 256 256
