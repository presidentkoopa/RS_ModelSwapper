# Rusted Legacy

![Rusted Legacy](https://i.imgur.com/pYvXhtz.png)

A VR focused mod for classic Doom by Ermac which takes full advantage of QuestZDoom VR port and features custom VR interactions and much more. Rusted Legacy mod also aims to add full VR support for the recent Doom addon Legacy of Rust.

This mod is a proof-of-concept for VR interactions in classic Doom engine (GZDoom) and using game assets found on internet for education purpose only. Please check credits list for sources of the assets used in the mod.

This mod is using some codes and assets from Brutal Doom mod (temporarily) and will replace them all gradually in the future.

## Features
* VR support for Lecagy of Rust
* VR weapons without/with hand models and with optional PBR textures
* VR interactions
* Manually Reload Weapons (optional)
* Wrist mounted VR HUD (optional)
* Weapon mounted VR HUD (optional)
* Aiming Laser for Weapons (optional)
* A throwable ShieldSaw!
* Compatible with other mods and maps

## Installation

### PC-VR

This mod runs on QuestZDoom PC-VR only (may make it compatible to GZDoomVR in the future)

Latest QuestZDoom PC-VR: https://github.com/emawind84/QuestZDoom/releases/latest

To install:

    Extract QuestZDoom to a folder.
    Copy original doom wads into the folder.
    Copy this mod into the folder.
    Run with qzdoom.exe -iwad doom2 -file LATEST_MOD_FILE
  
OR use DoomRunner: https://github.com/Youda008/DoomRunner/releases/latest to load mods with QuestZDoom

### Standalone (Meta Quest/Pico)

Official QuestZDoom: https://github.com/DrBeef/QuestZDoom/releases/latest

Unofficial QuestZDoom: https://github.com/emawind84/QuestZDoom/releases/latest

QuestZDoom launcher: https://github.com/baggyg/QuestZDoomLauncher/releases/latest

To install:

    Copy this mod into /sdcard/QuestZDoom/mods/
    Copy doom wads into /sdcard/QuestZDoom/wads/ or download FreeDoom/FreeDoom2 from QuestZDoom Launcher
    Load QuestZDoom Launcher. select this mod along with doom/doom2/freedoom/freedoom2

## Recommended mods to combine with:

* [VR Flashlight:](https://github.com/iAmErmac/VR-Flashlight)
  - Since the included flashlight has been removed, you are required to use this Flashlight mod instead

* [oVRdrive:](https://github.com/iAmErmac/overdrive)
  - Enables a lot of VR focused features such as positional melee attacks and force pull etc.
  
* [DamNums:](https://forum.zdoom.org/viewtopic.php?t=55048)
  - DamNums is a pretty simple concept: shoot monsters and little numbers pop out that tell you how much damage you did
  
* [Top HP Bars:](https://forum.zdoom.org/viewtopic.php?t=55048)
  - Really simple mod to add HP bars on top of enemies and players. Performance version is recommended for VR
