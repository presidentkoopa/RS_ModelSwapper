# quad/quad (MS_QD_Quad): four-barrel break-action shotgun

Owner upload 2026-11-03 (Quad_Shotgun.fbx + PBR textures). 12 rigid named parts, no rig, no animation.
Parts -> card: QShotgun_Frame body; Barrel / Lock / Handle hinge, hinge2, hinge3 (turn together); Ejector ejector;
Shotgun_Shell x4 shell..shell4 (seated 2x2 in the chambers by the artist); Trigger, TriggerFull trigger, trigger2;
Release lever. Hinge measured from the barrel lug's pin hole; the open/extract frames are authored from it (card
`source` block has the numbers). The 2x2 shell carve is one surface, like bd_ssg_shell. Read with fbxread.py /
fbx2obj.py (session tools). BaseColor 4096 -> 1024. Lock riding the barrel is an assumption: owner to confirm.
